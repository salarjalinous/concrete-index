Privacy

Last updated: November 20, 2026

The Concrete Index is a personal project run by Salar Jalinous. It has no accounts, sign-up, newsletter, advertising, or analytics. It sets no cookies and stores nothing in your browser.

What your browser sends, and to whom

Loading any page sends a standard web request to the site's host, GitHub Pages. GitHub logs the IP address of every visitor to a GitHub Pages site for security purposes, under GitHub's privacy statement. This site cannot see or change that log, and GitHub does not publish a retention period specific to Pages.

Most data pages ask public data services for figures directly from your browser. Those services receive your IP address and the query the page sends. Both run on Socrata, a platform operated by Tyler Technologies, which collects IP and network activity for its government clients under the Tyler Technologies privacy policy.

The Contracts page and the editorial pages (Methodology, About, Privacy, Terms, Sources) contact no host other than this site. Each page's Content Security Policy lists exactly the hosts above for that page, so the browser refuses any other connection.

What you type

When you run a Contractors search, the name you enter is sent to NYC Open Data, and to Open NY for the MTA and State section, as part of the query. Those operators can log it together with your IP address. Do not enter anything you would not want a public data service to receive. The search term is never written to the page address or to browser storage.

The Contracts search filters a file already downloaded from this site. It runs inside your browser and sends nothing.

What this site does not do

No cookies, local storage, session storage, tracking pixels, fingerprinting, or third-party scripts. Fonts, the charting library, and illustrations are served from this site. Requests to the data services carry no referrer. Payment data from Checkbook NYC and cost series from the U.S. Bureau of Labor Statistics are collected once a night by an automated job, so your browser never contacts either.

Questions and corrections

Open an issue on the project's GitHub issues page. Issues are public and are governed by GitHub's own terms and privacy statement, so leave out anything you would not post publicly.

This notice changes whenever a host is added to or removed from the list above, and the date at the top changes with it.
